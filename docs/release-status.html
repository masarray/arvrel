Closed-loop timing profile

Behavioral timing is explicit and externally correlated.

TESTSET

1 µs clock · 10 kHz BI

Monotonic integer-microsecond timing, 100 µs binary-input sampling, 0.5 ms deglitch, and zero debounce holdoff in the default CMC-style behavioral profile.

Relay

4 kHz / 250 µs processing

Instantaneous signed terminal samples feed clipping, quantization, 1.5 ms behavioral input delay, and a causal one-cycle rolling DFT.

Authority

Accepted BI1 edge

The TESTSET measured trip and optional auto-stop come only from the wired BI1 path, not from direct access to the relay's internal trip latch.

Fidelity boundary: this is a deterministic generic behavioral numerical-relay/test-set model. It is not calibrated equipment and does not claim the internal topology or uncertainty of a named commercial device.

Operator semantics

Timing events have distinct meanings.

EventMeaning
RELAY ANY PU [source]First generic protection pickup requesting BO2.
TESTSET BI2 ACCEPTAccepted generic ANY-PICKUP contact edge.
Operated-element pickup / P→TTiming belonging to the element that ultimately operates.
Relay trip requestLive relay trip-latch rising edge requesting BO1.
TESTSET BI1 ACCEPTAuthoritative external trip time and optional auto-stop trigger.

BI2 may legitimately precede the operated element's pickup because another enabled element can assert generic ANY PICKUP first.

Reset and validation

One reset transaction reaches a verified re-arm postcondition.

After BI1 auto-stop, beta.6 retains OUTPUT OFF · FROZEN CAPTURE. One RESET advances stale causal acquisition out, clears relay latch/timers once, waits for relay pickup and BO1/BO2 plus TESTSET BI1/BI2 to release, then exposes READY TO RE-ARM. Completed timing and evidence are preserved.
