Integrity procedure

Verify the exact downloaded bytes.

  1. Download the installer or portable package and SHA256SUMS.txt from the same GitHub Release.
  2. Calculate SHA-256 locally with Get-FileHash.
  3. Compare the entire hexadecimal value with the corresponding line in SHA256SUMS.txt.
  4. Stop if the value, filename, release tag, or source differs.
Get-FileHash .\ARVREL-Setup-v0.1.0-beta.4-win-x64.exe -Algorithm SHA256
Get-FileHash .\ARVREL-v0.1.0-beta.4-win-x64-portable.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
Expected result: the locally calculated value exactly matches the value published for that file in the same release.

Claim boundary

Integrity, reports and virtual controls do not convert laboratory software into operational equipment.

A valid checksum confirms downloaded bytes match the published file. Deterministic self-tests confirm packaged software behavior. Event-driven MMS reports and modeled SBO controls demonstrate laboratory behavior only. None establishes calibration, IEC 60255 type-test status, IEC 61850 conformance certification, hard-real-time behavior, commissioning approval, or switching authority.
