Current beta.6 capability map

From virtual test set to protection, process bus, transformer, and AVR evidence.

ARVREL separates signal source, virtual wiring, relay acquisition, protection logic, external TESTSET timing, process-bus trust, transformer engineering, and virtual control authority so each result can be explained.

Closed-loop feeder laboratory

Secondary injection with external virtual-I/O timing.

Source and wiring

Editable 4I+4V + virtual terminals

Configured RMS magnitude/angle sources drive instantaneous waveforms through explicit virtual analog wiring to relay terminals.

Relay front end

Causal acquisition

Signed terminal samples pass clipping, 16-bit-equivalent quantization, 1.5 ms behavioral delay, and a one-cycle rolling DFT on a 4 kHz grid.

TESTSET metrology

1 µs clock · 10 kHz BI

Independent binary inputs sample at 100 µs with separate 0.5 ms deglitch and zero debounce holdoff in the default profile.

External trip authority

Accepted TESTSET BI1 owns measured trip and optional auto-stop. Internal relay trip state is never a direct TESTSET shortcut.

Generic pickup authority

TESTSET BI2 represents wired ANY PICKUP and is explicitly distinct from the pickup of the element that ultimately operates.

One-click re-arm

RESET settles stale causal acquisition, clears relay state once, releases contacts/BI inputs, preserves frozen evidence, and reports READY TO RE-ARM only after the postcondition.

Capability boundary

Implemented behavior is not a stronger metrology or certification claim.

ARVREL remains virtual-output laboratory software. It does not claim calibrated secondary injection, a CMC or manufacturer-relay clone, IEC 61850 conformance, IEC 60255 type testing, commissioning acceptance, or protection-grade hard-real-time performance.
