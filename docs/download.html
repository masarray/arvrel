Verify SHA-256

Confirm the file before execution.

Compare the locally calculated hash with the corresponding line in SHA256SUMS.txt.

# Installer
Get-FileHash .\ARVREL-Setup-v0.1.0-beta.3-win-x64.exe -Algorithm SHA256

# Portable archive
Get-FileHash .\ARVREL-v0.1.0-beta.3-win-x64-portable.zip -Algorithm SHA256

# Inspect the published checksum file
Get-Content .\SHA256SUMS.txt
Expected result: the calculated hexadecimal SHA-256 value must exactly match the value published for that file in the same release.

Requirements

Prepare Windows and live-capture prerequisites.

Required for application and transformer self-test

  • Windows 10 or Windows 11 x64
  • Permission to run the selected installer or extracted executable
  • No Npcap, PCAP, or merging-unit hardware for the deterministic Transformer Self-Test

Required only for live SV capture

  • Npcap installed separately under its own license
  • An authorized Windows network adapter
  • An isolated laboratory process-bus network
  • SCL file for trusted SCL-bound operation
Windows reputation: the public site does not claim the current community binaries are Authenticode-signed. Verify the GitHub Release source and checksum; do not bypass organizational security policy.

Before first use

Establish deterministic software baselines before Live/Replay testing.

  1. Verify the downloaded package and checksum.
  2. Launch ARVREL without connecting a live adapter.
  3. Use Internal demo for the feeder baseline.
  4. Open Transformer differential IED · 87T / REF.
  5. Run RUN 10-SCENARIO SELF-TEST and expect PASS · 10/10 · transformer-public-beta-v1.
  6. Use COPY EVIDENCE if participating in public beta testing.
  7. Continue to PCAP replay, then Live Npcap, only when those paths are required.
Self-test boundary: 10/10 PASS verifies deterministic packaged software behavior. It is not calibration, IEC 61850 conformance, IEC 60255 type testing, or proof of physical trip performance.
