Verify SHA-256

Confirm the file before execution.

Compare the locally calculated hash with the corresponding line in SHA256SUMS.txt.

# Installer
Get-FileHash .\ARVREL-Setup-v0.1.0-beta.4-win-x64.exe -Algorithm SHA256

# Portable archive
Get-FileHash .\ARVREL-v0.1.0-beta.4-win-x64-portable.zip -Algorithm SHA256

# Inspect the published checksum file
Get-Content .\SHA256SUMS.txt
Expected result: the calculated hexadecimal SHA-256 value exactly matches the value published for that file in the same release.

Requirements

Prepare Windows and laboratory network prerequisites.

Required for internal simulation

  • Windows 10 or Windows 11 x64
  • Permission to run the selected installer or portable executable
  • No Npcap or merging-unit hardware for the internal AVR plant and transformer self-test

Required only for live Ethernet evaluation

  • Npcap installed separately for live Sampled Values capture
  • An authorized Windows network adapter
  • An isolated laboratory network
  • Appropriate engineering context for the selected IEC 61850 workflow
Windows reputation: the public site does not claim the current community binaries are Authenticode-signed. Verify the GitHub Release source and checksum; do not bypass organizational security policy.

Before first use

Establish deterministic software baselines before live testing.

  1. Verify the downloaded package and checksum.
  2. Launch ARVREL without connecting a live adapter.
  3. Use the internal feeder workflow for the protection baseline.
  4. Run the Transformer Differential 10-scenario self-test and expect PASS · 10/10 · transformer-public-beta-v1.
  5. Select AVR · OLTC Controller and verify the simulated transformer starts at tap 09/17.
  6. Review REMOTE + AUTO default operation before enabling the laboratory MMS server.
  7. When testing an IEC 61850 client, enable an RCB and confirm event-driven updates without manual polling.
  8. Continue to live/replay testing only when required and authorized.
Virtual authority boundary: modeled MMS controls act only on the virtual AVR/OLTC process. They do not command physical primary equipment.
