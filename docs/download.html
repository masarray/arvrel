Verify SHA-256

Confirm the file before execution.

Compare the locally calculated hash with the corresponding line in SHA256SUMS.txt.

# Installer
Get-FileHash .\ARVREL-Setup-v0.1.0-beta.1-win-x64.exe -Algorithm SHA256

# Portable archive
Get-FileHash .\ARVREL-v0.1.0-beta.1-win-x64-portable.zip -Algorithm SHA256

# Inspect the published checksum file
Get-Content .\SHA256SUMS.txt
Expected result: the calculated hexadecimal SHA-256 value must exactly match the value published for that file in the same release.

Requirements

Prepare Windows and live-capture prerequisites.

Required for the application

  • Windows 10 or Windows 11 x64
  • Permission to run the selected installer or extracted executable
  • An isolated evaluation environment appropriate for engineering software

Required only for live SV capture

  • Npcap installed separately under its own license
  • An authorized Windows network adapter
  • An isolated laboratory process-bus network
  • SCL file for trusted SCL-bound operation
Windows reputation: the public site does not claim the current community binaries are Authenticode-signed. Verify the GitHub Release source and checksum; do not bypass organizational security policy.

Before first use

Begin with the internal deterministic laboratory.

  1. Verify the downloaded package.
  2. Launch ARVREL without connecting a live adapter.
  3. Select Internal demo.
  4. Open relay settings and CT/VT context.
  5. Inject the deterministic A-G fault.
  6. Review trust state, waveform, phasors, relay LCD, event trace, and operation record.
