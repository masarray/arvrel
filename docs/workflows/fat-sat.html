Integration and review

Prepare demonstrations that expose the evidence behind the result.

Use deterministic internal scenarios, authorized synthetic sources, or sanitized replay material to prepare repeatable process-bus and protection demonstrations before formal project testing.

Use case

Reduce uncertainty before the formal test window.

ARVREL helps teams rehearse expected data, settings, trust states, and evidence presentation. It does not replace project procedures, calibrated injection equipment, approved test sheets, or acceptance authority.

Prepare

Define the scenario

Document the source, expected SV identity, CT/VT context, enabled elements, settings fingerprint, expected pickup, and expected virtual operation.

Demonstrate

Make the chain visible

Show packet identity, trust state, measured quantities, pickup, timer behavior, trip cause, relay LCD, and event evidence in one sequence.

Preserve

Capture review material

Export non-sensitive evidence and retain exact software version, source description, settings identity, and known limitations.

Preparation checklist

Control the variables before connecting live traffic.

Before the session

  • Confirm isolated and authorized network scope.
  • Use synthetic, sanitized, or contributor-owned captures.
  • Confirm ARVREL version and release package integrity.
  • Record intended SCL profile and stream identity.
  • Prepare enabled elements and settings fingerprint.
  • Agree which results are demonstration evidence only.

During the session

  • Begin with the internal deterministic A-G scenario.
  • Show mapping, scaling, continuity, quality, and freshness.
  • Demonstrate healthy and restrained trust states.
  • Review pickup and trip timing against the configured behavior.
  • Capture the operation record and event trace.
  • State all deferred functions and non-certified boundaries.
