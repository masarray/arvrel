Preparation and learning

FAT / SAT preparation

Education / research

Study signal provenance, timing domains, trust gating, operate/restrain behavior, virtual controls, and reproducible evidence.

Exercises

Repeatable lab modules

Run structured experiments for timing, protection, process bus, Transformer Differential, and AVR/OLTC.

Boundary

Workflow guidance does not expand authority.

ARVREL remains virtual-output behavioral laboratory software. Use approved calibrated equipment and procedures for formal commissioning acceptance, and use live Ethernet only on authorized isolated laboratory networks.
