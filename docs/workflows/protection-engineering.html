Protection engineer

Evaluate settings and virtual operation with visible provenance.

Follow the path from measured quantities and active settings to pickup, timer completion, directional supervision, trust permission, trip cause, and exported evidence.

Input

Known measurement context

Use the internal deterministic source, an authorized synthetic SV publisher, or a controlled replay with confirmed CT/VT context and channel provenance.

Evaluation

Native protection settings

Apply feeder elements, pickup values, curve or definite-time parameters, direction, characteristic angle, minimum polarizing voltage, and phase logic.

Output

Reviewable operation record

Inspect operated element, pickup and trip timestamps, phase/earth cause, operating quantity, angle where relevant, settings fingerprint, and trust state.

Recommended sequence

Separate protection behavior from communication uncertainty.

  1. Validate ARVREL with the deterministic internal A-G scenario.
  2. Set CT/VT context and confirm displayed secondary or primary quantities.
  3. Enable only the intended feeder elements; elements default disabled.
  4. Review pickup and timing before introducing live or replayed process-bus data.
  5. Confirm AllowsMeasurement, AllowsPickup, and AllowsTrip.
  6. Capture the operation record and active settings fingerprint.
  7. Repeat with one controlled variable changed at a time.

Protection scope

Implemented public-beta functions.

Current

50P-1, 51P, 50N, and 51N with pickup, dropout, definite or IEC inverse timing, TMS, and reset behavior.

Directional

67P using V1/I1 polarization and 67N using 3V0/3I0 polarization with direction, angle, voltage supervision, and definite delay.

Voltage

27, 59, and 59N using selectable voltage domains, phase logic, residual magnitude, dropout, and definite delay.

Not a settings authority: ARVREL does not replace protection coordination studies, certified relay testing, project approval, or commissioning acceptance.

Evidence checklist

Record enough context to reproduce the result.

Protection context

  • ARVREL version
  • Active element and settings group
  • Settings revision and SHA-256 fingerprint
  • CT/VT context and display domain
  • Input source and scenario description

Operation context

  • SMV trust state and permissions
  • Pickup and trip timestamps
  • Operating element and phase/earth cause
  • Operating quantity, unit, and directional evidence
  • Exported JSON or event trace
