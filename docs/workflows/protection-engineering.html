Workflows / Protection engineering

Feeder protection · beta.6

Separate relay operation from what the virtual test set actually measures.

Review source provenance, settings, causal relay acquisition, generic pickup, operated-element timing, relay contact behavior, external TESTSET BI timing, frozen evidence, and re-arm as separate engineering facts.

Before injection

Lock the engineering context.

  1. Confirm active feeder setting group, revision, CT/VT context, and settings fingerprint.
  2. Confirm which functions are enabled: 50P-1, 51P, 50N, 51N, 67P, 67N, 27, 59, or 59N.
  3. Review source setpoints and virtual analog/binary wiring.
  4. Define expected pickup, operate, restraint, and external TESTSET result before START.

Closed-loop run

Read each timing event according to its authority.

EventEngineering meaning
RELAY ANY PU [source]First generic pickup requesting BO2.
TESTSET BI2 ACCEPTAccepted wired ANY-PICKUP input; not necessarily the eventual operated-element pickup.
Operated-element pickupPickup belonging to the element that ultimately operates.
Operated-element P→TThat element's own pickup-to-trip interval.
Relay trip requestLive relay trip-latch edge requesting BO1.
TESTSET BI1 ACCEPTAuthoritative external trip time and optional source auto-stop trigger.
Critical invariant: internal relay trip state is never a direct TESTSET timing shortcut. Opening BO1→BI1 must remove the external measured trip even when the relay still operates internally.

Timing profile

Know the model behind the numbers.

TESTSET

1 µs monotonic clock resolution; 10 kHz BI sampling; 0.5 ms deglitch; 0 ms debounce holdoff.

Relay

4 kHz / 250 µs acquisition, instantaneous signed terminal samples, clipping/quantization, 1.5 ms behavioral delay, causal rolling DFT.

Timer edge

Definite/inverse timing starts at the first observed pickup frame. A representable 60 ms 50P delay produces 60.000 ms operated-element P→T.

Post-trip review

Freeze evidence without confusing it with live output.

  1. Confirm auto-stop occurs only from accepted BI1 when enabled.
  2. Verify OUTPUT OFF · FROZEN CAPTURE; configured setpoints may remain visible while effective output is zero.
  3. Review schema 9 timing timeline, operated-element attribution, capture-frame relationship, settings fingerprint, and topology/run identity.
  4. Press relay RESET once and wait for READY TO RE-ARM.
  5. Confirm completed timing/evidence remains available and the source has not been restarted or mutated.

Restraint and negative cases

Prove non-operation as deliberately as operation.

  • Below-pickup and dropout cases
  • Directional reverse cases for 67 functions
  • Voltage restraint/non-operate cases
  • Open BO1→BI1 wiring case
  • Process-bus trust blocks when replay/live data is used
  • Repeated run after one-click re-arm

Boundary

This workflow is behavioral engineering evidence.

It is not calibrated relay-test-set evidence, a named commercial relay equivalence result, IEC 60255 type-test evidence, or formal commissioning acceptance.
