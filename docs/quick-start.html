Five-minute evaluation

Validate the internal laboratory before connecting live traffic.

This first-run sequence confirms the operator workflow, deterministic source, measurement displays, protection settings, trust state, virtual trip, and operation evidence without requiring Npcap or external IEC 61850 equipment.

Before you begin

Use an official package and a controlled Windows environment.

1

Get the package

Download the installer or portable ZIP from GitHub Releases and verify SHA-256 when a checksum is published.

2

Keep live capture disconnected

Npcap and an external adapter are not required for the first evaluation.

3

Know the boundary

The result is virtual laboratory evidence, not calibrated relay-test or commissioning evidence.

Internal A-G scenario

Run the deterministic first test.

  1. Launch ARVREL.
  2. Select Internal demo as the process-bus source.
  3. Confirm that the workspace begins to show stable current and voltage quantities.
  4. Open CT/VT context and review the configured secondary/primary display basis.
  5. Open Relay settings. Confirm which feeder elements are enabled; elements default disabled until configured.
  6. Apply the intended demonstration settings.
  7. Select Inject A-G fault.
  8. Observe phase-A and residual quantities, waveform, phasors, pickup state, timing, and the virtual trip indication.
  9. Open the relay LCD or operation evidence view and confirm the operated element, phase/earth cause, timestamps, operating quantity, settings identity, and trust state.
  10. Reset the trip latch and repeat once to confirm reproducibility.

What success looks like

Review the chain, not only the red trip indication.

Measurement and trust

  • Stable complete waveform and phasor windows
  • Expected phase and residual quantities
  • Healthy internal-source trust state
  • AllowsMeasurement, AllowsPickup, and AllowsTrip consistent with the scenario

Protection and evidence

  • Expected element pickup and timing
  • Correct phase/earth cause attribution
  • Virtual trip latch and operated-element identity
  • Settings revision/fingerprint and exportable operation record

Next: replay or live SV

Add external data only after the internal path is understood.

PCAP / PCAPNG replay

  1. Use a synthetic, sanitized, or authorized capture.
  2. Select replay and identify the intended SV stream.
  3. Import SCL when available.
  4. Confirm mapping, scaling, continuity, quality, and trust before interpreting protection behavior.

Live Npcap capture

  1. Install Npcap separately under its own license.
  2. Use an isolated, authorized laboratory network.
  3. Select the intended adapter and bind the stream.
  4. Do not connect ARVREL to an operational process bus without explicit authorization and an approved test method.
Never use the internal demo result as proof of field performance. It validates the software workflow and deterministic scenario only.

Troubleshooting routes

Move to the relevant evidence page.

No measurement or unstable stream

Review identity, mapping, scaling, continuity, quality, freshness, and complete-window readiness.

Pickup visible but trip restrained

Review the three trust permissions and the evidence that removed trip authority.

Build or launch problem

Use the Windows setup guide for source layout, execution-policy-safe commands, and rebuild steps.
