Laboratory 1 · SIG-001

Fundamental phasor and sequence reconstruction

Objective: connect a balanced sampled waveform to complex RMS phasors and symmetrical components without calling the method a full FFT.

Procedure

  1. Review AN-01 and the FundamentalPhasorEstimator source.
  2. Run the filtered SIG-001 automated test.
  3. Record the 80-sample window, RMS targets, and phase angles.
  4. Explain mean removal and the single fundamental DFT bin.
  5. Compare phase and positive-/negative-sequence results.

Expected evidence

  • IA magnitude near 2 A RMS
  • VA magnitude near 63.5 V RMS
  • I1 near 2 A
  • I2 near zero for the balanced fixture
  • Explicit statement: no full harmonic-spectrum FFT claim
dotnet test .\tests\Arvrel.Protection.Tests\Arvrel.Protection.Tests.csproj -c Release `
  --filter "FullyQualifiedName~FundamentalEstimator_ReturnsRmsMagnitudeAndBalancedPositiveSequence"
Read AN-01

Laboratory 2 · TRUST-001

Pickup visibility with trip restraint

Objective: demonstrate why a protection pickup indication and permission to assert a new trip are not equivalent.

Procedure

  1. Review the three trust permissions.
  2. Run the filtered TRUST-001 test.
  3. Identify the phase-current pickup condition.
  4. Apply the trip-blocked SMPCNT_GAP trust state.
  5. Record pickup, blocked state, and trip-latch result.
  6. Explain how rejected or discontinuous communication evidence affects operation authority.

Expected evidence

  • Phase pickup is visible
  • Protection state reports blocked
  • No new virtual trip latch
  • Trust reason is preserved
  • No claim that visibility equals trusted operation
dotnet test .\tests\Arvrel.Protection.Tests\Arvrel.Protection.Tests.csproj -c Release `
  --filter "FullyQualifiedName~SmvTrustGate_BlocksOperationWithoutHidingPickup"

Laboratory 3 · DIR-001 / DIR-002

Forward operation and reverse restraint for 67P

Objective: connect V1/I1 phasor angle, characteristic angle, torque sign, directional selection, timer, and virtual operation.

Procedure

  1. Review the directional torque equation in AN-03.
  2. Run the paired forward/reverse automated test.
  3. Record V1 and I1 angles, MTA, torque, and selected direction.
  4. Compare the forward operate case with the reverse restraint case.
  5. Explain the role of minimum polarizing voltage and trust permission.

Expected evidence

  • Forward case enters selected region
  • Configured delay completes
  • Forward case latches virtual trip
  • Reverse case does not pick up
  • Reason text records angle, MTA, torque, and direction
dotnet test .\tests\Arvrel.Protection.Tests\Arvrel.Protection.Tests.csproj -c Release `
  --filter "FullyQualifiedName~DirectionalPhase67_TripsForwardAndRestrainsReverse"
Read AN-03

Laboratory 4 · Evidence report

Turn a passing scenario into a reviewable engineering record.

  1. Select one operate scenario and one restrain or blocked scenario.
  2. Record source, version, settings identity, scenario ID, expected result, and observed result.
  3. Include pickup, operation, direction, trust, and timing evidence where applicable.
  4. Explain limitations and any deviation from the deterministic fixture.
  5. Attach only sanitized exports and non-sensitive screenshots.
  6. Cite ARVREL using CITATION.cff.
Recommended conclusion format: “The referenced ARVREL version reproduced the expected software behavior for the stated synthetic fixture. The result is not calibration, type-test, conformance, commissioning, or operational evidence.”

Assessment boundary

Laboratory success does not authorize plant operation.

These exercises are educational and research workflows. They do not provide switching authority, protection-setting approval, commissioning acceptance, physical trip output, calibrated test evidence, or a hard-real-time performance claim.
