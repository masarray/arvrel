One workspace for the protection cause-and-effect chain

From Ethernet evidence and SCL binding to RMS/phasor measurement, active settings, virtual trip, and exportable records.

Live and replay process bus

Npcap live capture plus PCAP/PCAPNG replay with APPID, VLAN, svID, datSet, confRev, quality, freshness, mapping, scaling, and smpCnt evidence.

Coherent instruments

4I+4V one-cycle protection phasors, symmetrical components, two-cycle waveform evidence, residual channels, primary/secondary display, and held healthy frames during recovery.

Protection evidence

Per-element pickup timing, operated-element attribution, trip quantity and unit, settings fingerprint, SMV trust state, and latched phase/earth causes.

Practitioner workflow

Familiar I>, I0>, TMS, tI>, tMin, and tReset notation with native settings, preset files, CT/VT context, and curve-time previews.

Research workflow

Read-only active algorithm source and deterministic shadow validation. Staged research artifacts cannot replace the running standard algorithm.

Trust before trip

Rejected duplicate/out-of-order frames never enter measurement buffers. Recent continuity, quality, scaling, or SCL issues visibly remove virtual trip permission.

Start with the internal laboratory, then connect an authorized SV source

The official beta package is self-contained for Windows x64. Npcap remains a separately licensed prerequisite for live capture.

  1. Download the installer or portable ZIP from GitHub Releases.
  2. Launch ARVREL and validate the deterministic internal A-G fault.
  3. Import an SCL file, select an adapter, and bind the intended SV stream.
  4. Set CT/VT context and protection settings.
  5. Observe trust state, waveform, phasor, LCD, operation record, and evidence export.

Clear engineering boundary

ARVREL is virtual-output laboratory software. It is not a certified protection IED, calibrated relay test set, operational GOOSE trip source, MMS controller, switching authority, or IEC 60255 type-test result. Use live features only on isolated, authorized test networks.
