Not yet validation of hardware equivalence

Software regression evidence has a defined ceiling.

The current scenario set can demonstrate deterministic behavior of the referenced ARVREL code and fixtures. It cannot establish traceable test-set calibration, manufacturer-specific relay timing, IEC 60255 type-test compliance, IEC 61850 conformance, protection-grade hard-real-time execution, commissioning acceptance, or operational suitability.

Reproducibility rule

Do not publish a scenario without an exact executable reference.

Public deterministic scenarios should point to a source file, test file, exact test method, declared input, expected result, and bounded evidence class. New research claims require new fixtures and tests before documentation is expanded.
