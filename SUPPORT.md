# Support

## Community support

The GPL community edition is provided without a service-level agreement. Use GitHub issues for reproducible defects, documentation problems, and focused feature proposals. Include the ARVREL version, Windows version, source mode, synthetic SCL/profile details, and relevant logs.

Community support does not include protection-study approval, operational switching authority, substation cybersecurity assessment, IEC conformance certification, or emergency response for production systems.

## Commercial support

Separately negotiated commercial services may include private deployment assistance, integration engineering, training, prioritized maintenance, response-time commitments, private features, OEM terms, or technical workshops. See [`COMMERCIAL-LICENSING.md`](COMMERCIAL-LICENSING.md).

A commercial engagement exists only after a written agreement is signed. Public issues do not create an SLA or warranty.

## Safe diagnostic material

Use synthetic or contributor-owned files. Do not publish customer captures, proprietary SCL files, credentials, IP plans, station names, or employer-confidential information.
