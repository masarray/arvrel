# Security and operational-risk policy

ARVREL is a laboratory application. Report software vulnerabilities privately through the repository security-advisory workflow when available. Do not publish credentials, station SCL files, customer captures, network plans, device addresses, or other restricted operational information in public issues.

P0 contains no active GOOSE trip, MMS control, physical output, or autonomous switching path. Any future active network function must remain disabled by default, require explicit laboratory arming, expose its destination and state, support dry run, and preserve independent evidence.

Only connect live process-bus features to an isolated, authorized test network. ARVREL does not establish switching authority, isolation, interlocking adequacy, functional safety, or IEC 61850 conformance.
